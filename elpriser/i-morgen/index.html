Elpriser i morgen, time for time

Se morgendagens spotpriser, så snart de offentliggøres omkring kl. 13. Planlæg opvask, vask og opladning af elbil efter de billigste timer. Tallene hentes fra Energinet og vises inkl. moms.

Emil Rostgaard Clausen, stifter og redaktør

Det korte svar: Morgendagens elpriser fastsættes på elbørsen og offentliggøres normalt omkring kl. 13 dagen før. Før det tidspunkt viser siden dagens priser. De billigste timer ligger typisk om natten og midt på dagen, de dyreste mellem kl. 17 og 21.

Hvornår kommer elpriserne for i morgen?

Elbørsen Nord Pool lukker auktionen for næste døgn kl. 12, og priserne offentliggøres normalt mellem kl. 12.45 og 13.15. Energinet lægger dem på Energi Data Service kort efter, og så opdateres denne side automatisk. Før det tidspunkt viser grafen dagens priser, og knappen "I morgen" er grå.

Sådan planlægger du morgendagen efter elprisen

  1. Find de billigste timer

    Se boksen "Billigste sammenhængende timer". Den finder det billigste tidsrum på 2, 4 og 6 timer i morgen, fx til opvasker, vask og tørring eller opladning af elbil.

  2. Sæt maskinerne på timer

    De fleste opvaskere og vaskemaskiner har udskudt start. Mange elbiler og ladebokse kan styres efter elprisen i appen.

  3. Undgå kl. 17-21

    Her er både spotprisen og nettariffen typisk højest. Kan noget vente til efter kl. 21, er det næsten altid billigere.

Hvorfor kan prisen i morgen være meget anderledes end i dag?

Vejrudsigten styrer det meste. Spår meteorologerne blæst, falder morgendagens pris ofte markant, og på solrige dage kan middagstimerne blive gratis eller negative. Vindstille og koldt vejr giver det modsatte. Derfor kan to dage i træk ligge langt fra hinanden.

Spotprisen kan du ikke vælge. Tillægget kan du.

Alle betaler den samme spotpris i samme landsdel. Forskellen på elselskaberne er det tillæg, de lægger oven i hver kWh, og det faste abonnement. De tre billigste ved 4.000 kWh (22. oktober 2026):

  1. Nordisk Energi: 5 øre + 0 kr./md. = 200 kr. om året
  2. Altid Energi: 0 øre + 18 kr./md. = 216 kr. om året
  3. Enkel Energi: 0 øre + 18 kr./md. = 216 kr. om året

Spørgsmål og svar om elpriser

Hvornår kommer morgendagens elpriser?

Elbørsen offentliggør priserne for det kommende døgn omkring kl. 13. Herefter kan du se dem på siden med elpriser i morgen.

Hvornår er strømmen billigst?

Som regel om natten mellem kl. 00 og 06 og midt på dagen i sommerhalvåret, når solcellerne producerer mest. De dyreste timer ligger typisk mellem kl. 17 og 21. Blæsevejr trækker prisen ned.

Hvad er forskellen på DK1 og DK2?

Danmark er delt i to prisområder ved Storebælt. DK1 er Jylland og Fyn, DK2 er Sjælland, Lolland-Falster og Bornholm. Priserne er ofte ens, men kan afvige, når forbindelserne til nabolandene er fyldt op.

Kan elprisen blive negativ?

Ja. Når der produceres mere strøm, end der bruges, kan spotprisen gå under nul. Du betaler stadig tariffer og moms, så den samlede pris bliver sjældent negativ.

Hvorfor kan jeg ikke se priserne for i morgen endnu?

Priserne for næste døgn offentliggøres normalt omkring kl. 13. Før det viser siden dagens priser, og knappen 'I morgen' er ikke aktiv.

Hvor præcise er morgendagens priser?

Helt præcise. Det er de endelige børspriser for hvert kvarter i morgen, ikke en prognose. Kun din samlede pris afhænger af nettarif, afgifter og dit elselskab.
